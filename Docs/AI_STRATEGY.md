# AI 전략 가이드

> 카탄 6가지 핵심 전략 + 초보자가 피해야 할 실수 정리

---

## 6가지 핵심 전략

### 1. Full OWS (Ore-Wheat-Sheep)

| 항목 | 내용 |
|------|------|
| 핵심 자원 | 광석, 밀, 양모 |
| 승리 구성 | 도시 3개 + 최대기사단 + 발전카드 승점 2장 |
| 장점 | 빠른 도시 업그레이드, 발전카드 대량 구매 |
| 단점 | 나무/벽돌 미생산 → 도로/마을 건설 어려움, 은행 4:1 교환 의존 |

### 2. Road Builder (도로 건설자)

| 항목 | 내용 |
|------|------|
| 핵심 자원 | 나무, 벽돌 |
| 승리 구성 | 최장교역로 + 마을/도시 확장 |
| 장점 | 도로 경쟁에서 거의 항상 승리 |
| 단점 | 광석/밀 부족 → 도시 건설 어려움, 세 번째 마을을 광석/밀 생산지에 짓는 게 핵심 |

> 6가지 전략 중 가장 고급 전략. 세부적인 플레이가 많이 요구됨.

### 3. Five Resource (5자원)

| 항목 | 내용 |
|------|------|
| 핵심 자원 | 5종 균등 |
| 승리 구성 | 도시 + 마을 확장으로 생산력 극대화 |
| 장점 | 교역 의존도 낮음, 독립적 플레이 가능, 초보자 친화 |
| 단점 | 최장교역로/최대기사단 어느 쪽도 확보 어려움, 강한 상대에게 불리 |

### 4. City + Road (도시 + 도로)

| 항목 | 내용 |
|------|------|
| 핵심 자원 | 광석, 밀 (도시) + 나무, 벽돌 (도로) |
| 승리 구성 | 도시 4개 (8점) + 최장교역로 (2점) |
| 장점 | Road Builder 없는 게임에서 이상적 |
| 단점 | 양모 의도적 배제 → 양모 풍부한 보드에서 교역 필요 |

### 5. Port (항구 전략)

| 항목 | 내용 |
|------|------|
| 핵심 자원 | 특정 자원 대량 생산 + 2:1 항구 |
| 승리 구성 | 항구 교환 활용한 유연한 자원 운용 |
| 장점 | 할 일 없는 턴이 거의 없음 |
| 단점 | 초반이 느림, 항구 도달까지 시간 소요 |

> 중급자 상대로 오히려 어려울 수 있음 — 2:1 항구 위력을 과대평가하여 자원을 과도하게 차단하는 경향.

### 6. Hybrid OWS (하이브리드 OWS) — 최강 전략

| 항목 | 내용 |
|------|------|
| 핵심 자원 | 광석, 밀, 양모 + 나무/벽돌 소량 |
| 승리 구성 | Full OWS + 도로/마을 건설 보완 |
| 장점 | 가장 범용적, 충분한 광석/밀만 있으면 어디서든 사용 가능 |
| 조건 | 광석 4핍 이상, 밀 4핍 이상, 양모 2핍 이상 |

---

## 전략 간 경쟁 구도

```
최대기사단 계열          최장교역로 계열
  Full OWS        ←→     Road Builder
  Hybrid OWS      ←→     City + Road
       └─── 5자원 / 항구가 틈새 공략 ───┘
```

## 초보자가 피해야 할 7가지 실수

### 실수 1: 고정된 전략에 집착

- 항상 5자원만 가져가거나, 무조건 2:1 항구만 노리는 패턴
- **프로**: 보드 상황에 따라 6가지 전략 중 최적을 선택하고 조합

### 실수 2: 상대의 배치를 예측하지 않기

- 좋은 자리 보면 바로 건설
- **프로**: 보드 전체를 먼저 분석 → 두 번째 배치 때 남을 자리 예측, 희소 자원/항구 위치/해안 자리 파악 후 결정

### 실수 3: 첫 도로를 보드 중앙으로 향하게 놓기

- 중앙의 좋은 자리는 상대에게 먼저 점령됨
- **프로**: 첫 도로를 해안 쪽으로 → 빈자리가 남아 있을 가능성 높음
- 예외: 나무/벽돌 풍부한 플레이어는 중앙 빈자리를 공격적으로 노릴 수 있음

### 실수 4: 쉬운 행동부터 먼저 하기

- OWS 플레이어가 발전카드만 사고, 나무/벽돌 플레이어가 도로만 까는 패턴
- **프로**: 어려운 행동을 먼저 → 교역을 통해 전략적 마을 건설 우선
- 어려운 목표를 나중으로 미루면 게임 후반에 막힘

### 실수 5: 자급자족 체제 없이 앞서 나가기

- **프로**: 도시 1개 + 항구 마을로 자급자족 기반을 먼저 구축
- 기반 없이 승점을 앞서가면 → 다른 플레이어의 차단/도적/교역 거부로 고립
- 중·후반에는 교역이 줄어들기 때문에 독립 운영 기반이 핵심

### 실수 6: 교역을 거부할 이유 찾기

- 상대에게 이점 준다는 이유로 교역 회피
- **프로**: 교역할 이유를 적극적으로 탐색
- 4인 게임에서 교역 = 2명 이득, 2명 손해 → 실질적 2인 경쟁으로 전환 가능
- 1:1뿐 아니라 2:1, 2:2, 조건부 거래도 활용

### 실수 7: "자기 차례만 기다리는 게임"으로 생각하기

- **프로**: 상대 턴에도 적극적으로 플레이
  - 상대 손패 추적
  - 상대 강점/약점 지속 평가
  - 상대 턴에 더 좋은 거래 성사 가능
  - "테이블 토킹"으로 상대 간 거래 방해
- 보드 인식 능력 = 상위 플레이어와 일반 플레이어를 가르는 핵심 차이
