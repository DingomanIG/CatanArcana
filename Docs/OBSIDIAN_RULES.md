# Obsidian 작성 규칙

> `Docs/` 볼트 내 문서 작성 시 준수할 포맷 규칙

---

## 프론트매터 (YAML)

모든 `Docs/` 문서에 YAML 프론트매터 필수:
```yaml
---
tags:
  - type/기획          # 문서 유형
  - phase/1            # 관련 Phase
  - status/진행중       # 문서 상태
created: 2026-04-15
updated: 2026-04-15
---
```

---

## 태그 체계

| 카테고리 | 태그 | 용도 |
|---------|------|------|
| **유형** | `type/기획`, `type/설계`, `type/QA`, `type/레퍼런스`, `type/TODO`, `type/가이드` | 문서 분류 |
| **Phase** | `phase/1`, `phase/1-3`, `phase/2` | 개발 단계 |
| **상태** | `status/완료`, `status/진행중`, `status/대기` | 문서/작업 상태 |
| **도메인** | `domain/네트워크`, `domain/AI`, `domain/UI`, `domain/카드`, `domain/보드` | 기능 영역 |

---

## 문서 템플릿 (유형별)

### 기획/설계 문서 (`type/기획`, `type/설계`)
```
# 제목
> 한 줄 요약

---
## 개요
## 상세 내용 (테이블/다이어그램 활용)
## 구현 순서 (체크리스트)
## 주의사항
---
## 관련 문서
- [[링크]] — 설명
```

### QA/테스트 문서 (`type/QA`)
```
# 제목
> 테스트 도구/조건 설명

---
## 범례 (상태 마커 등)
## 테스트 항목 (체크리스트)
## 알려진 버그 (테이블)
---
## 관련 문서
```

### TODO 문서 (`type/TODO`)
```
# 제목
> 용도 설명

---
## 카테고리별 섹션
- [ ] 미완료 항목
- [x] 완료 항목 ✅ YYYY-MM-DD
---
## 관련 문서
```

### 레퍼런스 문서 (`type/레퍼런스`)
```
# 제목
> 출처/참고 링크

---
## 핵심 내용 (테이블/헤더 구조화)
---
## 관련 문서
```

---

## 체크박스 포맷

| 마커 | 용도 | 예시 |
|------|------|------|
| `- [ ]` | 미완료 | `- [ ] 항목` |
| `- [x]` | 완료 | `- [x] 항목 ✅ YYYY-MM-DD` |
| `- [C]` | 조건부 통과 (QA 전용) | 재테스트 필요 |
| `- [D]` | 수정대기 (QA 전용) | 수정 완료, 재테스트 대기 |

---

## 공통 규칙

- 문서 간 참조는 반드시 `[[위키링크]]` 사용 (그래프뷰 연동)
- 문서 하단에 `## 관련 문서` 섹션 필수
- 테이블 적극 활용 (비교/목록 데이터)
- `---` 구분선으로 주요 섹션 구분
- 인라인 경로 참조: 백틱 대신 `[[위키링크]]` 우선
