# 아르카나 그리드 (ArcanaGrid) - 게임 디자인 문서

> **버전**: 1.3 (MVP 설계서)
> **장르**: 전략 보드게임 (듀얼 모드)
> **모드**: 아르카나 머천트 (클래식) / 아르카나 패들러 (로그라이크)
> **플랫폼**: WebGL (Unity)
> **개발사**: 희영소프트 (Heyoung Soft)

## 0. 개요

### 0.1 게임 개념

하나의 코어 엔진 위에 **두 가지 게임 모드**를 제공하는 전략 보드게임.

- **아르카나 머천트** (Arcana Merchant): 클래식 모드 — 정통 보드게임 룰 (승점 10점, PvP, 플레이어 간 거래)
- **아르카나 패들러** (Arcana Peddler): 로그라이크 모드 — 떠돌이 행상인의 런 기반 전략 (Ante 진행, 골드 경제, 조커 빌드, PvE)

두 모드는 헥스 그리드, 자원 생산, 건물/도로 시스템을 공유하며, **룰셋만 분기**한다.

### 0.2 듀얼 모드 아키텍처

```
메인 메뉴 → 모드 선택
├─ 아르카나 머천트 (Arcana Merchant)
│    ├─ 룰: 정통 보드게임
│    ├─ 승리: 승점 10점 선착
│    ├─ 대전: PvP (2~4인) + AI 대체 가능
│    ├─ 거래: 플레이어 간 협상 + 은행/항구
│    ├─ 보드: 고정 19 헥사 (표준)
│    └─ 세션: 40~60분
│
└─ 아르카나 패들러 (Arcana Peddler)
     ├─ 룰: 로그라이크 확장
     ├─ 승리: Ante 8 클리어 (누적 골드)
     ├─ 대전: PvE (AI 도전자와 간접 경쟁)
     ├─ 거래: 시스템만 (항구/방랑상인/은행)
     ├─ 보드: Ante별 스케일링 (9→42 타일)
     ├─ 추가: 청사진, 상점, 조커, 골드 경제
     └─ 세션: 20~30분
```

### 0.3 공유 시스템 vs 모드 전용 시스템

| 시스템 | 머천트 | 패들러 | 공유 여부 |
|---|---|---|---|
| 헥스 그리드 / 좌표계 | O | O | **공유** |
| 주사위 (2d6) | O | O | **공유** |
| 자원 생산 (5종) | O | O | **공유** |
| 건물 배치 (마을/도시/도로) | O | O | **공유** |
| 개발카드 (기본) | O | O | **공유** |
| 도적 | 기본 | 강화 (서든데스) | **분기** |
| AI | 대전 상대 | 런 도전자 | **분기** |
| 승리 조건 | 승점 10 | Ante 골드 | **모드 전용** |
| 플레이어 간 거래 | O | X | **머천트 전용** |
| 청사진 / 조커 시스템 | X | O | **패들러 전용** |
| 상점 페이즈 | X | O | **패들러 전용** |
| 골드 통합 경제 | X | O | **패들러 전용** |
| Ante 스케일링 | X | O | **패들러 전용** |

### 0.4 기술 구현 방향

- `IGameManager` 인터페이스에 `GameRuleset` (Merchant / Peddler) 추가
- 룰 의존 로직만 분기, 코어 시스템(그리드/건물/자원)은 공유
- `GameBootstrapper`에서 모드 선택 → 적절한 매니저 생성
- UI는 공통 HUD + 모드별 패널 (머천트: 거래창 / 패들러: 상점)

### 0.5 패들러 모드 핵심 차별점

- **건물 = 조커**: 건설 즉시 패시브 효과 부여
- **청사진 시스템**: 상점에서 골드로 청사진 구매 → 자원으로 건설. 청사진은 런 내 Ante 간 유지
- **플레이어 간 거래 삭제**: 은행/항구/상인을 통한 시스템 거래만 존재
- **서든데스 라운드 구조**: 턴 제한 없음, 시간이 지날수록 도적 강화
- **공용 상점 페이즈**: 모든 플레이어 동시 구매
- **골드 통합 경제**: 승점, 화폐, 건물 가치를 골드 하나로 통합

### 0.6 세션 목표

| | 머천트 | 패들러 |
|---|---|---|
| **세션 시간** | 40~60분 | 20~30분 |
| **승리 조건** | 승점 10점 | Ante 8 클리어 |
| **플레이어** | 2~4인 PvP | 1인 PvE + AI 도전자 |
| **리플레이** | 맵 랜덤 배치 | 런마다 빌드 다양성 |

## 1. 머천트 → 패들러 모드 변경 사항 요약

> 이하 섹션 2~12는 **패들러 모드** 전용 룰. 머천트 모드는 정통 보드게임 룰을 그대로 따른다.

| 영역 | 머천트 모드 | 패들러 모드 |
|---|---|---|
| 주사위 | 합계 매칭 | 빨강/노랑 d6, 합계 매칭 (MVP) → 5가지 매칭 방식 (v1.1+) |
| 타일 숫자 | 고정 1개 | 최대 3개 (업그레이드 가능) |
| 타일 종류 | 자원별 구분만 | 일반 타일 (MVP) → 빨강/노랑/페어/황금 추가 (v1.1+) |
| 건물 | 승점 획득 | 청사진(골드) → 건설(자원) → 조커 효과 패시브 |
| 거래 | 플레이어 간 협상 | 완전 삭제 |
| 개발카드 | 즉시 사용 | MVP에선 기본만, 점진 추가 |
| 상점 | 자기 턴에 구매 | 라운드 종료 후 공용 페이즈 |
| 도적 | 자원 절반 상실 + 타일 봉쇄 | 타일 봉쇄 + 턴당 자원 -2 |
| 승리 조건 | 승점 10점 | Ante 8 클리어 (누적 골드) |
| 보드 | 고정 19 헥사 | Ante별 그리드 확장 (9→42) |
| 플레이어 | PvP 4인 | PvE 협동 (AI 도전자 동행) |

## 2. 게임 루프

### 2.1 전체 구조

```
[런 시작]
  ├─ Ante 1 (3×3 그리드, AI 0명)
  │    └─ 라운드 1
  │         ├─ 모든 플레이어 턴 순환 (서든데스, 목표 달성까지)
  │         ├─ 목표 골드 달성 체크
  │         └─ 상점 페이즈 (전원 동시)
  ├─ Ante 2 (3×4 그리드, AI 1명)
  ├─ ...
  └─ Ante 8 (6×7 그리드, AI 3명) → 승리
```

### 2.2 턴 진행

한 플레이어의 턴:

1. **주사위 굴림** (빨강 d6 + 노랑 d6)
2. **타일 발동** (매칭된 타일들이 자원 생산)
3. **도적 효과 적용** (활성 시)
4. **건물 건설** (자원 소비, 선택적)
5. **개발카드 사용** (선택적)
6. **턴 종료**

### 2.3 라운드 종료 조건 (서든데스)

- 목표 골드 달성 시 즉시 라운드 종료
- 턴 제한 없음
- 단, **도적이 시간에 따라 강화**되어 장기화 시 압박 증가

## 3. 주사위 & 타일 시스템

### 3.1 주사위

- **빨강 d6** + **노랑 d6** (색깔 구분된 2개)
- 한 번 굴림에 다양한 매칭 방식 동시 판정

### 3.2 타일 유형

**MVP**: 일반 타일만 (합계 매칭)

| 유형 | 매칭 조건 | 발동 확률 | 비고 | 스코프 |
|---|---|---|---|---|
| **일반** | 빨+노 합계 매칭 | 2.78~13.89% | 숫자에 따라 차등 | **MVP** |
| **빨강** | 빨강 주사위만 매칭 | 16.67% | 안정적 생산 | v1.1+ |
| **노랑** | 노랑 주사위만 매칭 | 16.67% | 안정적 생산 | v1.1+ |
| **페어** | 빨=노 (같은 눈) | 2.78% (특정) / 16.67% (전체) | 중간 희귀도 | v1.1+ |
| **황금** | 빨X AND 노Y (특정 조합) | 2.78% | 최고 희귀, 최고 보상 | v1.1+ |

### 3.3 타일 숫자 스택 (업그레이드)

- **기본**: 타일당 숫자 1개
- **1차 강화**: 숫자 2개 (발동 확률 2배 근접)
- **2차 강화**: 숫자 3개 (발동 확률 3배 근접)
- 상점에서 "숫자 페인트" 구매로 강화

### 3.4 생산량 밸런스 (5×5 기준 시뮬 결과)

- 50턴 한 런 기준 **평균 약 195개 자원** 생산
- 턴당 평균 **3.9개 자원**
- 타입별 기여도:
  - 일반 타일: 34.8%
  - 빨강/노랑: 각 17%
  - 페어: 17%
  - 황금: 14.9% (생산 10배 기준)

### 3.5 황금 타일 밸런싱

- **기본 생산 10배** (일반 타일 1 → 황금 10)
- 변동계수 0.524 (도박성 구조)
- 황금 전용 조커로 스노우볼 빌드 성립 유도

## 4. 건물 = 조커 시스템

### 4.1 핵심 원칙

**청사진 → 건설 2단계 시스템**:
1. **청사진 구매**: 상점에서 골드로 청사진 카드 획득 (런 내 Ante 간 유지)
2. **건물 건설**: 보유 자원을 소비하여 보드에 건설 → 조커 효과 발동

건물을 짓는 순간 = 조커 슬롯에 장착되는 순간. 물리적 보드 배치가 곧 조커 장착.

### 4.2 건물 카테고리

| 카테고리 | 역할 | 예시 |
|---|---|---|
| 마을 (Settlement) | 기본 점수 배수 | +50 골드, 인접 타일 효과 |
| 도시 (City) | 마을 업그레이드, 대형 배수 | +150 골드, 타일 생산 2배 |
| 자원 전문 | 특정 자원 강화 | 목재소, 석공소, 제분소 |
| 특수 | 방어/이자/시세 | 수도원, 시장, 요새 |
| 교역 | 자원 교환 특화 | 항구, 방랑상인 배치 |

### 4.3 조커 규모

- **MVP (1차 프로토타입)**: 15~20종
- **얼리 액세스**: 30~40종
- **정식 출시**: 50~60종
- **DLC/모드 여지**: +30~50종

### 4.4 조커 분류 축 (10개)

1. 주사위 조작 (리롤, 눈 +1, 색 변환)
2. 타일 강화 (숫자 스택, 인접 확산) — ⚠️ 인접 효과는 복잡성 우려로 고려 중
3. 자원 배수 (특정 자원 ×N)
4. 건물 배수 (도시 건설 시 ×N)
5. 황금/페어 특화 (저확률 고배율)
6. 도적 방어 (면역, 역습)
7. 시세 조작 (시장가 예측) — **v1.0 스코프 제외**
8. 방랑상인 (상인 슬롯, 효과 강화)
9. 이코노미 (라운드 종료 시 골드, 이자)
10. AI 상호작용 (약탈, 봉쇄) — **v1.0 스코프 제외**

### 4.5 건물 등급 (Edition)

| 등급 | 효과 | 가격 배수 |
|---|---|---|
| 일반 | 기본 효과 | 1× |
| 강화 (Foil) | +50 칩 | 2× |
| 홀로 (Holo) | +10 멀티 | 3× |
| 폴리크롬 (Poly) | ×1.5 멀티 | 5× |
| 네거티브 | 조커 슬롯 차지 안 함 | 희귀 드랍 |

### 4.6 건물 되팔기

- **구매가의 50% 고정 환급**
- 빌드 피벗 가능
- 긴급 자금 확보 수단
- 보드 공간 재활용

## 5. 거래 시스템 (3층 구조)

### 5.1 플레이어 간 거래: 완전 삭제

협상 시간 제거로 게임 속도 2~3배 상승. 모든 거래는 시스템을 통한 교환만 존재.

### 5.2 3층 거래 수단

**A. 항구 (Port)**
- 해안 고정 위치
- 2:1 특화 교환 (자원 지정)
- 영구 건설형 조커

**B. 방랑상인 (Wandering Merchant)**
- 개발카드로 호출 가능
- 매 턴 타일을 **랜덤으로 이동** (고정 배치 아님)
- 방랑상인이 위치한 타일에서 특수 교환 가능
- 특수 효과 가능 (밀수꾼, 환전상, 정보상, 고리대금업자, 카라반 마스터 등)

**C. 은행 (Bank)**
- 전역 접근 가능
- **4:1 교환** (비효율, 최후 수단)
- 이자/대출 기능 포함

### 5.3 거래 효율 순위

**방랑상인 > 항구 > 은행**

## 6. 골드 통합 경제

### 6.1 골드의 3가지 역할

1. **승점**: 블라인드 목표 = 누적 골드 X 달성
2. **화폐**: 상점 조커/타일/바우처 구매
3. **건물 가치**: 판매 시 50% 환급

### 6.2 골드 획득 경로

**A. 건물 건설**
- 마을: +50 골드
- 도시: +150 골드
- 최장 도로: +200 골드
- 기사단: +200 골드

**B. 자원 → 골드 변환** (조커 효과)
- 시장 조커: 라운드 종료 시 자원 1개당 +2 골드
- 정제소 조커: 돌 1개 소비 → 15 골드
- 방앗간 조커: 밀 생산 시 +3 골드

**C. 이자**
- 라운드 종료 시 **보유 골드의 10%**
- 상한: 50 골드 (최대 +5 이자)
- 관련 조커로 확장 가능

**D. 주식증서 배당**
- 하단 "주식증서" 섹션 참조

**E. 특수 조커 효과**
- 상인: 라운드 종료 시 +10 골드
- 세금 징수원: AI 타일 발동 시 +1 골드
- 광부: 황금 타일 발동 시 +50 골드

### 6.3 건물 점수 공식 (선택 C안)

```
건물 배치 시 즉시 골드:
  = 기본 건물 점수 × 타일 자원 칩 × 조커 멀티

예시:
  돌 타일(칩 25) + 도시(점수 150) + 석공조합 조커(×1.5)
  = 150 × 25 × 1.5 = 5,625 골드

라운드 종료 시 추가 골드:
  = 보유 건물 × 생산 효율 보너스 + 이자 + 주식 배당
```

### 6.4 카탄 승점 요소 취급

- **마을/도시**: 건설 시 즉시 골드 획득 (승점 개념 승계)
- **최장 도로/기사단**: 조커 슬롯화 → 빌드 선택지
- **개발카드 승점**: 즉시 골드 획득

## 7. 주식증서 시스템 — **v1.0 스코프 제외**

> **스코프락**: 경제 레이어 과잉 방지를 위해 v1.1+로 이동. 코어 루프 검증 후 추가.

<summary>상세 설계 (v1.1+ 참고용)</summary>

### 7.1 개념

골드를 투자하면 매 라운드 고정 배당. 이자보다 수익률 높지만 초기 비용 큼. **언제 사느냐가 핵심 판단**.

### 7.2 주식증서 3종

| 등급 | 구매가 | 배당/라운드 | 원금 회수 | 비고 |
|---|---|---|---|---|
| **채권 (Bond)** | 50 골드 | +8 골드 | 7 라운드 | 안전, 초반용 |
| **주식 (Stock)** | 150 골드 | +25 골드 | 6 라운드 | 중반 주력 |
| **블루칩 (Blue Chip)** | 400 골드 | +80 골드 | 5 라운드 | 후반 폭발 |

### 7.3 주식 슬롯

- **조커 슬롯과 분리**된 전용 주식 슬롯 3개
- 조커 슬롯 점유 안 함
- 판매 시 구매가 50% 환급

### 7.4 주식 관련 조커

- **투자자**: 주식 배당 +50%
- **금융업자**: 주식 슬롯 +2
- **내부자**: 채권 구매가 -30%
- **공격적 포트폴리오**: 블루칩 배당 +100%, 이자 수령 불가
- **분산투자**: 서로 다른 3종 주식 보유 시 모든 배당 +25%
- **배당왕**: 매 라운드 보유 주식 1종당 +5 골드

### 7.5 불확실성 이벤트 (선택적, v1.1+)

Ante 시작 시 10% 확률:

- 호황: 주식 배당 x2 (1 Ante)
- 불황: 주식 배당 x0.5 (1 Ante)
- 파산: 보유 주식 1종 소멸
- 배당 특별 지급: 즉시 배당 x3

## 8. 도적 시스템

### 8.1 트리거 조건

**빨+노 합 7 AND 차이 1** (3+4 또는 4+3)

- 확률: 2/36 = 5.56%
- 50턴 기준 평균 2.8회 발동

### 8.2 기본 도적 효과

- **타일 사보타지**: 타일 1개 N턴간 봉쇄 (자원 생산 중단)
- **매 턴 랜덤 카드 -2**: 도적 활성 동안 매 턴 시작 시 랜덤 자원 2장 상실

### 8.3 시간 누적 강화 (서든데스 압박)

```
라운드 지속 턴수별 도적 확률:

1~5턴:   평상시 (5.56%, 합7+차이1)
6~10턴:  증가 (16.67%, 모든 합7)
11~15턴: 추가 증가 (25%, 합7 또는 합6/8)
16턴+:   매 턴 도적 발동 (100%)
```

### 8.4 도적 해제 조건

- 기사 개발카드 사용
- 도적 방어 조커 ("경비병", "은신처", "요새" 등)
- N턴 후 자동 해제

### 8.5 도적 방어 조커 풀

- **경비병** (Common): 도적 확률 -30%
- **은신처** (Uncommon): 도적 발생 시 자원 상실 면제
- **요새** (Rare): 도적 효과 완전 무효화, 단 자원 -1/턴
- **도적 포획자** (Rare): 도적 발생 시 AI 타일도 봉쇄 + 골드 +50
- **기사단장** (Legendary): 기사 카드 무제한 사용

### 8.6 왕귀 빌드 보상 조커

- **인내**: 10턴 이상 지속 라운드 시 종료 시 골드 ×1.5
- **장인**: 15턴 이상 지속 라운드 시 모든 건물 +1 승점
- **성전**: 20턴 이상 지속 라운드 시 다음 상점 리롤 무료

## 11. AI 도전자

### 11.1 정체성

- **런 도전자** (보스 역할 아님)
- 플레이어와 같은 블라인드 목표를 추격
- **직접 방해**: 건물/도로 위치 선점으로 플레이어 확장 방해 + 도적 이동으로 타일 사보타지
- **간접 경쟁**: 공용 상점에서 조커 선점

### 11.2 AI 기본 행동 루프

1. 자기 턴에 주사위 굴림
2. 자원 생산
3. 건물 건설 (가능한 경우)
4. 개발카드 사용
5. 턴 종료

### 11.3 AI 상점 행동

- 라운드 종료 후 플레이어와 함께 구매
- 보유 골드와 현재 빌드에 맞춘 구매 우선순위
- 희귀 조커 선점 시 플레이어에게 긴장감 부여

### 11.4 AI 난이도 스케일링

- Ante 2~3 AI: 기본 건설만
- Ante 4~5 AI: 조커 시너지 이해
- Ante 6~8 AI: 최적화된 빌드 경쟁

### 11.5 AI 방해 행동 (MVP)

- **위치 선점**: 유리한 교차점/변에 먼저 건설하여 플레이어 확장 차단
- **도적 사보타지**: 기사 카드 사용 시 플레이어 핵심 타일에 도적 배치

### 11.6 확장 요소 (v1.1+)

- AI와의 강제 거래 (공물 요구)
- AI 건물 파괴/인수 (대전 모드)
- AI 직접 공격 조커
